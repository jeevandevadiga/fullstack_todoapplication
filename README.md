# ✨ TodoFullstack

> A beautiful, full-stack Todo application built with modern technologies.

A clean and intuitive task management application that helps you stay organized and productive. Built with a focus on performance, simplicity, and great user experience.

---

## 🚀 Features

- ✅ Create, edit, and delete tasks
- 📌 Mark tasks as complete/incomplete
- 🗂️ Organize tasks with categories/tags
- 🔍 Search and filter tasks
- 📱 Fully responsive design
- 🌙 Dark mode support
- ⚡ Real-time updates (if using WebSocket/Socket.io)
- 🔐 User authentication (optional)

---

## 🛠 Tech Stack

| Layer       | Technology                          |
|-------------|-------------------------------------|
| **Frontend**    | React + TypeScript + Tailwind CSS   |
| **Backend**     | Node.js + Express                   |
| **Database**    | MongoDB                             |
| **Authentication** | JWT + bcrypt                     |
| **State**       | React Query / Zustand               |
